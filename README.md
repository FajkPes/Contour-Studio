# Contour Studio

A Windows tool for extracting and exploring image contours.

## Key features

- Adjust detection settings and preview the resulting geometry.
- Export compact CGR5 contour data.
- Inspect processing and rendering statistics.

## Get started

Download the ZIP from Releases and run `Spustit.bat`. Windows App Runtime 1.8 is required.
